# Watershed Lab — интерфейс

Карта и панель анализа Watersheds на React, Vite, MapLibre GL и Recharts.

Полная инструкция установки, подключения данных и работы с приложением — в
[основном README](../README.md). Архитектура, API и настройки размещения описаны
в [руководстве разработчика](../docs/development.md).

## Локальный запуск

Из этой папки, при уже запущенном Flask API на `http://127.0.0.1:5000`:

```sh
npm ci
npm run dev
```

Vite проксирует `/api/*` на backend. Откройте адрес, напечатанный в терминале.
Для картографических подложек нужен интернет; для расчётов — локальные растры.

## Проверки

```sh
node --test src/lib/*.test.js
npm run lint
npm run build
```

Сборка создаёт `dist`. Прокси сервера разработки в неё не входит: для размещения
нужно настроить reverse proxy `/api` или задать `VITE_API_URL` перед сборкой.
